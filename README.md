# Alexander Domanov Portfolio

Static portfolio website built with HTML, SCSS, and vanilla JavaScript.

## Requirements

- Node.js ^20.19.0 or >=22.12.0
- npm

## Setup

```sh
npm install
```

## Development

Start the Vite development server with HMR:

```sh
npm run dev
```

Vite serves the site locally and processes the SCSS entry point from `scss/main.scss`.

## Production build

Create the production build in `dist/`:

```sh
npm run build
```

Preview the production build locally:

```sh
npm run preview
```

## Checks

Run read-only JavaScript, SCSS, HTML, and formatting checks:

```sh
npm run check
```

Apply available automatic fixes explicitly:

```sh
npm run fix
```
